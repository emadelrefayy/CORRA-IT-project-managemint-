# KORRA IT Project Management

## Run locally on Replit

- Install dependencies with the package manager when `package.json` changes.
- Start the web app with `npm run dev`.
- The Vite development server listens on `0.0.0.0:5000` and allows Replit's proxied preview hosts.

## External service

The frontend reads project data through the Replit Supabase connector. Connect a Supabase project in Replit before expecting live project, asset, network, or maintenance data to load.
